# HomeSquare

Australian owner-direct residential property advertising marketplace. HomeSquare is **not** a real estate agency; buyers and sellers use their own conveyancers/solicitors for contracts and settlement.

## Prototype

Open `index.html` in a browser. No build step is required. The landing page, property filtering, draft listings, local publishing, enquiries, and seller dashboard are interactive.

**Important:** This is a local-browser demo, not a production marketplace. Data is stored in localStorage on each device, so different users cannot see each other's listings or enquiries. No authentication, email delivery, backend, real payments, identity verification, photography bookings, signboard orders, or secure offers exist yet. The 'publish' toggle publishes only inside the same browser.

## Next milestones

1. Establish database, authentication and role-based permissions.
2. Owner verification and listing moderation, photo uploads and public listing pages.
3. Buyer accounts, secure enquiry inbox, inspections and offer tracking.
4. Subscription billing and optional in-house photography and signboard services.
5. Automated tests, accessibility, security review and deployment.

## Hosting

A static preview can be hosted with GitHub Pages or Netlify, but do not collect real personal data through the prototype; it lacks a secure backend.
